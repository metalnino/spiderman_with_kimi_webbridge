### 继续停用及其理由

- 园林养护：探针 4/6 为「株洲市园林养护一所/二所」网超采购（单位名误命中）；业务形态「园林绿化养护」已被 绿化养护 子串覆盖 → 不启用。
- 道路绿化：工程（崧泽高架工程道路绿化项目）/市场价格调查/预算编制为主；「道路绿化养护」已被 绿化养护 覆盖 → 不启用。
- 足球场养护/球场养护：仅赣州（非目标城）同一项目命中，目标城 0 覆盖 → 不启用（如需球场草坪业务再评估）。
- 工程/景观族（屋顶绿化、立体绿化、垂直绿化、绿墙、绿雕、花境、补植、移栽）：以建设项目/工程分包/苗木扩繁为主，与养护服务业务形态不匹配 → 停用。绿雕/花境养护类标题（如「城市绿雕、花箱及花境养护项目」）少且多与市政菊展/大赛材料混合，暂不启用。
- 采购族（苗木采购、花卉采购、盆栽、植物墙）：供应侧采购，与投标养护业务不匹配 → 停用。

## 维护口径

1. 增删启用词 = 三层同步：config.active + DB keyword_state + config/keywords.json（员工外壳默认输入）。
2. 新词启用前先跑 scripts/probe_kw_library.py 看第 1 页量与标题形态；再决定拆分变体。
3. 变体拆分判据：站点严格子串匹配时，「办公绿化」类总括词必须配「办公区绿化/办公室绿化/办公场所绿化」类变体。
4. 首轮启用新词会触发水位冷启动（ccgp 每词最多 6 页、chinabidding 3 页，空页即停），耗时比日常增量长，属一次性成本。
5. 词库只读全貌：scripts/jobs/kw_analysis.py → data/kw_analysis_out.json。
