# 开发文档目录（唯一过程文档源）

本目录约束本仓库的开发与验收。Agent / 人工开发均以这里为准。

## 你怎么用（产品侧）

你只需关心两件事：

1. **当期阶段是否开发完成**（见 `phases/当前阶段.md` 的开发勾选）
2. **测试是否通过**（见同文件的测试勾选 + `testing/验收清单.md`）

全部勾选 = 该阶段完成，才能进下一阶段。

## 文档地图

| 文件 | 用途 |
|------|------|
| `product_plan.md` | 产品范围、分期、不做清单 |
| `architecture.md` | 技术架构与模块边界 |
| `anti_bot.md` | 反爬：HTTP 主 + WebBridge 辅 |
| `data_model.md` | MySQL 与字段约定 |
| `filters_cascade.md` | 筛选级联规则 |
| `testing/开发测试流程.md` | 通用：怎么测、怎么验 |
| `testing/验收清单.md` | 总验收（跨阶段） |
| `phases/P0.md` … | 阶段任务 + 完成定义 + 测试项 |
| `changelog.md` | 关键决策简记 |

机器可读配置仍在 `config/*.json`；若冲突，**以本目录文档的产品决策为准，并回写配置**。
