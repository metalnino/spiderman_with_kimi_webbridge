# 产品计划

## 目标

绿植招采线索持续运营台：固定 4 站增量抓取 → 清洗 → MySQL → 可筛可看；关键词可迭代。

## 固定源站

1. cebpub（招标投标公共服务平台）
2. chinabidding（采招网，列表级）
3. ggzy（全国公共资源交易平台）
4. ccgp（中国政府采购网）

## 默认产品假设

- 增量排序默认：首次发现时间
- 可全国入库；列表默认可筛 7 城
- UI：内部台账；先不做权限体系
- 不上 Scrapy / Airflow

## 明确不做（本期）

- 自动投标、标书生成
- 多租户权限
- 为防封而全程只用浏览器裸爬
